# SGit

**Simple version control for everyone.**

SGit is a planned lightweight command-line version-control tool designed to make saving, tracking, and recovering file changes easier to understand.

Unlike traditional developer-focused tools, SGit aims to use beginner-friendly terminology and straightforward interactions.

## Project Goals

- Make version control accessible to beginners.
- Support ordinary folders, not just programming projects.
- Provide an understandable way to save file versions.
- Explore temporary change storage and recovery.
- Keep the experience simple and approachable.

## Technology

- **Language:** C#
- **Platform:** .NET
- **Interface:** Console / CLI
- **Development status:** Planning
